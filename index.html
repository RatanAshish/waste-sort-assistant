Waste Sort Assistant

Type any household item and get instant guidance on which bin it belongs in — and why.

This demo runs on a rule-based classification engine so it works fully offline on any static host (like GitHub Pages). In production, the same input/output contract is designed to be served by a prompt-engineered LLM call for open-ended coverage of any item — see classifyWaste() in the source for the underlying logic and the system prompt design notes in the comments.
